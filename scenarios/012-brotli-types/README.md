# 012-brotli-types — brotli_types の重複警告

## 何を測るか

`brotli_types` に重複した MIME 型を書いたとき、nginx が何を言うか。**警告文・出る条件・重大度を実物のログから取ります。**

🔴 **警告文を推測で書きません。** 「重複警告が出るはず」という予測はあっても、実際の文言と重大度（`warn` か `emerg` か）はログを見るまで分かりません。出なければ「出なかった」と書きます。

## 前提として分かったこと

🔴 **公式 nginx イメージには Brotli モジュールが入っていません。** 企画時のカード②はそのままでは成立しないため、Alpine の配布パッケージから**版を固定して**組みます。

| 項目 | 値 |
|---|---|
| イメージ | `http-examples-brotli:1.28.3-r7`（`brotli/Dockerfile`）|
| nginx | `nginx-1.28.3-r7`（alpine 3.22・**stable**）|
| モジュール | `nginx-mod-http-brotli-1.28.3-r7` |

他のシナリオで使う公式 mainline **1.31.3** とは版が違います。この差は測定記録に明記します。

## 記事のどこに出るか

決定表 1 の設定注意。

## 判定

3 つの設定を `nginx -t` にかけ、出力をそのまま保存します。

| case | 設定 |
|---|---|
| a | `text/html` を明示的に書く（常に対象の型を重ねる）|
| b | 同じ型を 2 回書く |
| c | 対照。重複なし |

## 実行

```bash
bash scenarios/012-brotli-types/run.sh
```

サーバは起動しません。`nginx -t` の出力だけを見ます。
