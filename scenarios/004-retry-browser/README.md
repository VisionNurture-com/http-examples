# 004-retry-browser — ブラウザは待ってくれるか

## 何を測るか

ページの `fetch` から 429 + `Retry-After: 3` を受け取り、**そのあと 9 秒のあいだに再送が届くか**を 3 エンジンで測ります。

## 判定

判定はサーバ側の到着記録で行います。`Retry-After` の 3 倍だけ待ってから到着回数を数え、1 回のままなら再送していないと読みます。

## 記事のどこに出るか

実効値の表「Retry-After に従うのは誰か」。「`Retry-After` を付ければ待ってもらえる」という前提を検算する箇所。

## 実行

```bash
bash scenarios/004-retry-browser/run.sh
```
