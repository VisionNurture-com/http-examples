# 004-auth-headed — 測定装置が結果を決めていないか

## 何を測るか

[`004-auth-browser`](../004-auth-browser/README.md) と同じ 5 アームを、**headless と headed の両方**で通します。同じブラウザ・同じ応答で結果が変わるなら、それは応答の性質ではなく測定装置の性質です。

## なぜ要るか

006 では Playwright が bfcache を全ブラウザで無効化していたため、実ブラウザでしか測れない範囲がありました。401 の扱いにも同種の差がないかを、先に確かめます。

## 判定

ナビゲーションの応答が**ページへ渡ったか**を見ます。渡らなかった場合は、ブラウザが 401 を自分で処理しようとした側と読みます。

🔴 **ダイアログそのものは測っていません。**実 Chrome を占有できず、自動化はプロンプトを自前で打ち切るためです。Firefox / WebKit については「プロンプトを出さなかった」のか「自動化が抑止した」のかを本装置では分けられません。**未測定として記録します。**

## 記事のどこに出るか

実効値の表「401 に添える WWW-Authenticate」の但し書き。測れた範囲と測れていない範囲の線引き。

## 実行

```bash
bash scenarios/004-auth-headed/run.sh
```
