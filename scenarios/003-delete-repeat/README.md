# 003-delete-repeat

2 回目の DELETE が何を返すかを、3 通りの実装で測ります。

## 何を測るか

同じ DELETE を 2 回送り、次の 2 つを**別々に**記録します。

- サーバ状態が 1 回目のあとと 2 回目のあとで同じか
- 応答（ステータス + 本文）が同じか

| 変種 | 実装 |
|---|---|
| `strict` | 存在を確かめ、無ければ 404 |
| `lenient` | 確かめずに消して 204 |
| `echo` | 消した結果を 200 の本文で返す |

## 実行

```bash
docker compose up -d --wait
bash scenarios/003-delete-repeat/run.sh
```

## 測り方の注意

このシナリオは、冪等性を「応答が同じこと」と取り違えないために置いています。判定を 2 系統に分けているのはそのためです。
