# 006-etag — no-cache のときに何が起きるか

## 何を測るか

`no-cache` は「キャッシュするが、使う前に必ず検証する」指定です。検証で済むか全文が飛ぶかは、**応答が検証子を持っているか**で決まります。

nginx は静的ファイルに `ETag` と `Last-Modified` を既定で付けます。そこで `etag off` と `Last-Modified` の除去で検証子を消した経路を並べ、条件付きリクエストの結末を比べます。

## 埋める欄

決定表の「検証のコスト」列。

## 判定

curl で 1 回目の検証子を取り、`If-None-Match` を付けた 2 回目の status を見ます。
