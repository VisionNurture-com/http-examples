# 006-expires-directive — nginx の expires が実際に出すヘッダ

## 何を測るか

`expires` に何を書くとどのヘッダが出るのかを全数で確かめます。公式ドキュメントは値ごとの対応を書いていますが、**記事に載せる値は自分で出させて確認したものを使います**。

これは競合（006-expires-conflict）を議論するための土台です。「`expires` が何を出すか」が確定していないと、`add_header` との衝突の話ができません。

## 埋める欄

決定表の「nginx でどう書くか」列。

## 判定

curl が受け取ったヘッダ全行。同名ヘッダをまとめずに配列で記録します。
