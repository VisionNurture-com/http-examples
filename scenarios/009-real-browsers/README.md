# 009-real-browsers — ホストの実ブラウザで測る

## 何を測るか

`009-redirect-browser` と同じ 7 ケースを、**実際に配布されているブラウザ**で測ります。

Playwright 1.62.1 が同梱する Firefox は 153.0 で、stable の 154.0 より 1 メジャー古いままです。測っている対象がクライアントの挙動そのものである以上、版は結論に効きます。同梱版だけで測って「3 エンジンで一致した」と書くと、**一致を確かめていないものを確かめたことにしてしまいます**。

## 記事のどこに出るか

決定表の脚注（測った版）と、「同梱版と実ブラウザで結果が一致したか」の 1 行。

## 判定

ページ自身が 7 ケースを測り、結果をサーバへ POST します（Playwright から Firefox / Safari の実バイナリを駆動できないため）。判定基準は `009-redirect-browser` と同じで、サーバ側の到着記録を読みます。

## 測れない範囲

**ブラウザは測定時点のホストにある版だけ**です。Chrome は 151 系で、upstream の stable は 152 系でした（2026-08-23 時点）。
