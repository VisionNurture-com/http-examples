# 006-proxy-cache — 共有キャッシュは private をどう扱うか

## 何を測るか

`private` は「共有キャッシュに保存するな」という指定です。ところが nginx の公式ドキュメントは、proxy_cache が `Cache-Control` を「キャッシュのパラメータを設定する」としか書いておらず、**`private` を受けたら保存しないとは明記していません**。

そこで nginx を共有キャッシュとして立て、上流（アプリ）が返す `Cache-Control` を振って、**上流に何回届いたか**を数えます。共有キャッシュに当たった分は上流に届きません。

`Cache-Control` を何も付けない場合も測ります。**指定がない応答は `proxy_cache_valid` の設定に従って保存されます。**

## 記事のどこに出るか

決定表の「リソース種別」軸（ユーザー固有か公開か）。

## 判定

上流アプリの到着カウンタ（`/006/api/hits`）と `X-Cache-Status`。2 系統が一致することを確認します。
