# 004-auth-dialog — ダイアログは本当に出るのか

## 何を測るか

401 + `WWW-Authenticate: Basic` で、**実ブラウザがネイティブの認証ダイアログを出すか**を撮ります。対照は `Bearer` の 401 と、プロキシで challenge を剥がした 401 です。

## なぜ自動化と分けるのか

[`004-auth-headed`](../004-auth-headed/README.md) は Playwright で測りましたが、**自動化は資格情報のプロンプトを自前で打ち切る**ため、「出さなかった」のか「抑止された」のかを分けられませんでした。ここは実アプリで撮り、目視で判定します。

測るのは**自動化していない実アプリ**です。Playwright 同梱のブラウザとは版もビルドも違うため、両方の版を記録します。

## 判定

目視。画面にサインインを求める入力欄が出たかどうかと、本文が表示されたかどうかを読みます。証拠は `results/004-auth-dialog/*.png` に残します。

## 記事のどこに出るか

実効値の表「401 に添える WWW-Authenticate」。「401 を返すとログイン画面が出てしまう」という読者の症状そのものの裏づけ。

## 実行

```bash
bash scenarios/004-auth-dialog/run.sh
```
