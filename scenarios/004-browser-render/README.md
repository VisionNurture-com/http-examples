# 004-browser-render — ブラウザはコードを見ているか

## 何を測るか

**同じ本文**を、コードだけ変えて返します。ブラウザが本文を描画するか、スクリプトを実行するかをコードごとに見ます。

対象は 200 / 403 / 404 / 410 / 429 / 500 / 503 の 7 コード × 3 エンジンです。

## 判定

本文に置いた目印（`BODY-RENDERED-<code>`）が DOM に現れたか、スクリプトが設定する目印（`SCRIPT-RAN-<code>`）が付いたかの 2 点で見ます。**描画とスクリプト実行を分けて読む**ためです。

## 記事のどこに出るか

実効値の表「前段はコードで何を変えるか」。「コードを正しく選べば読者に伝わる」という前提を検算する箇所。

## 実行

```bash
bash scenarios/004-browser-render/run.sh
```
