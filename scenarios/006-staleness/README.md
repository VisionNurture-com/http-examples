# 006-staleness — 直したのに反映されない

## 何を測るか

キャッシュの相談は「効かない」から始まりますが、効かせたあとに来るのは反対側の困りごとです。`max-age` を長くすると、サーバのファイルを直しても期限が切れるまでブラウザは取りに来ません。

1. `max-age=600` で配ったアセットを読み込む
2. **サーバ側のファイルを差し替える**
3. もう一度ページを開く → 取りに来るか / 画面はどちらの版か
4. URL を変える（キャッシュバスティング）→ 取りに来るか / 画面はどちらの版か

ブラウザが今どちらの版を適用しているかは、CSS カスタムプロパティ `--rev` を読んで確認します。到着記録だけでは「取りに来ていない」ことは言えても「古い版を見ている」ことは言えません。

## 埋める欄

決定表の「更新頻度」軸。

## 判定

サーバ側の到着記録 + ブラウザが適用している CSS の版（`--rev`）。2 系統が一致することを確認します。
