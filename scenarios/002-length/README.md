# 002-length — 本文が黙って消える

## 何を測るか

`Content-Length` は本文の長さを伝えるヘッダです。**削ったときに何が起きるか**を測ります。「壊れる」と思われがちですが、結果は違いました。

3 通り送ります。

| 送り方 | 狙い |
|---|---|
| 既定 | curl が `Content-Length` を付ける |
| `-H "Content-Length:"` | 長さの申告だけを消す |
| `-H "Transfer-Encoding: chunked"` | 長さを使わない枠組みで送る |

## 判定

応答コードだけでは足りません。**サーバに何バイト届いたか**を、受け取ったものをそのまま返す口（`/002/api/echo`）の `bodyBytes` で見ます。

## 記事のどこに出るか

決定表の「壊れないが結果が変わる」欄。もっとも見つけにくい型の実例。
