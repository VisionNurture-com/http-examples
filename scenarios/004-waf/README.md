# 004-waf — その 403 は誰の判断か

## 何を測るか

同じ状況でも、返すのがサーバ（アプリ）なのか前段なのかで、403 の中身は変わります。ここでは前段に OWASP CRS（ModSecurity）を遮断モードで置き、次の 2 つを並べます。

| 由来 | 中身 |
|---|---|
| **アプリの 403** | 認証は通ったが権限が足りない、という認可の判断 |
| **WAF の 403** | 要求そのものが遮断された（本文はアプリまで届いていない） |

あわせて、WAF を越えたときに `WWW-Authenticate` / `Retry-After` / Problem Details の本文が残るかを測ります。

## 判定

応答コード・`Content-Type`・本文の 3 点。**コードだけでは 2 つを見分けられない**ことを示すのが目的です。

## 記事のどこに出るか

実効値の表「401 に添える WWW-Authenticate」と「前段はコードで何を変えるか」。「403 が返った」から先に進むには何が要るか、の裏づけ。

## 実行

```bash
bash scenarios/004-waf/run.sh
```
