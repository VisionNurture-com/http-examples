# 003-safe-get

「GET は安全」という言い方の実際を測ります。

## 何を測るか

状態を変える GET（トークンを 1 つ消費する）を用意し、次の 3 つを記録します。

1. GET を 3 回送ったときの消費数
2. **HEAD を 1 回送ったときの消費数** — `app.head()` を書いていない状態で、Express が HEAD をどこへ回すか
3. 対照として、本当に読むだけの GET が状態を動かさないこと

2 が中心です。自分で書いた危険な GET を自分で確かめても循環になるため、**自分では書いていない経路**が同じハンドラに落ちることを見ます。

## 実行

```bash
docker compose up -d --wait
bash scenarios/003-safe-get/run.sh
```

ブラウザの先読みが同じ GET を踏むかは `003-prefetch`（M2）で測ります。
