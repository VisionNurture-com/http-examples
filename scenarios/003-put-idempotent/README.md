# 003-put-idempotent

「PUT だから冪等」がどこまで言えるかを、4 通りの実装で測ります。

## 何を測るか

同じ本文の PUT を 3 回送り、そのつど `GET /003/state` で状態を取ります。相異なる状態の数が 1 なら、その実装は測った範囲で冪等に振る舞っています。

| 変種 | 実装 |
|---|---|
| `replace` | 受け取った本文で丸ごと置き換える |
| `stamped` | 保存時に `updatedAt` をサーバの時計で打つ |
| `append` | 受け取った本文を履歴に足す |
| `numbered` | 保存のたびにリビジョンを振る |

対照として、毎回リソースを作る POST も同じ手続きで測ります。

## 実行

```bash
docker compose up -d --wait
bash scenarios/003-put-idempotent/run.sh
```

## 測り方の注意

- 状態はアプリのプロセス内に残るため、変種ごとに `POST /003/__reset` で初期化しています
- `stamped` は同じミリ秒に収まると差が消えるため、送信のあいだに 50ms 空けています。測っているのは実装の冪等性であって時計の分解能ではないためです
- 冪等性の判定に応答は使いません（RFC 9110 の定義はサーバ状態への効果であり、応答の同一性ではありません）
