# 002-duplicate-order — 並びと重複

## 何を測るか

「ヘッダの順番は関係ない」「同じ名前を 2 回書いたらどうなるか」という 2 つの通説を測ります。

## curl では測れない

curl は `Host` を重複させてくれません。2 本書いても 1 本に畳みます。**curl で測ると「重複しても 200 だった」という誤った実測が出ます。**

そこで生ソケットでバイト列を自分で組み、リクエストをそのまま流します。

## 測るもの

| ケース | 組み方 |
|---|---|
| 並び替え | 同じ 2 本を順序だけ入れ替える |
| 同名の重複 | `X-Sample` を 2 本 |
| `Host` の重複 | `Host` を 2 本（RFC 9112 §3.2） |

## 判定

応答コードと、サーバが実際に見た値・並びを `/002/api/echo` の返す JSON で読みます。

## 記事のどこに出るか

決定表の「並びは変えてよいか」「重複はどう畳まれるか」欄。

## 実行

```bash
bash scenarios/002-duplicate-order/run.sh
```
